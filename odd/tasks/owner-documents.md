# Owner documents (role C «Documentación»)

Objective: a dedicated owner page for the community documents, reachable from the sidebar, matching the provided mockup, on top of the existing single document library (no second repository) with the highest security guarantees. Branch `feat/owner-documents` (stacked on `feat/owner-issues`). Delivery: single-pr (as owner-issues). Runners: `npx ng test` (frontend), `npx jest --testPathPatterns=<pattern>` in `backend/` (integration specs need local Postgres), Playwright (demo DB: `E2E_OWNER_EMAIL=propietario@demo.domora.app`, `E2E_OWNER_PASSWORD=Demo2026!`; neighbour `moroso@`, manager `gestora@`; login throttle 5/min per email).

## Specs

- S1. (L1) "Buscador de documentos y botón de filtros avanzados." Search by name, description and category (content search out of scope: PDFs are not indexed). Advanced filters, not duplicating the category chips: date range, file type, only new, property (in «Todas mis propiedades»).
- S2. (L1) "Categorías: Todos, Actas, Económicos, Normativa, Seguros, Contratos y Otros." (L2) "la categoría sale de la carpeta raíz": Actas = «Actas y juntas», Económicos = «Contabilidad y presupuestos», Normativa = «Documentación legal», Seguros = «Seguros», Contratos = «Contratos y mantenimiento», Otros = «Certificados e inspecciones» + manager-created root folders + documents without folder. Chips show counts computed inside the visible set.
- S3. (L1) "Listado con nombre, categoría, fecha y tamaño del documento." Icon by file type, description under the name, coloured category pill, download and «⋯» menu per row; sort by date/name/size; «Nuevo» marker and «Marcar todo como leído».
- S4. (L1) "Vista previa del documento seleccionado, con opciones de abrir y descargar." / "Clic en una fila para consultar el documento." Right panel: title, description, category, type and size, «Fecha de publicación», «Publicado por» («Administración de la comunidad» / «Generado por Domora»), viewer (PDF and images only), «Descargar» (original file and name) and «Abrir documento» (new tab). Deep link `?doc=<id>`; full-screen viewer on phones.
- S5. (L1) "Descarga de documentos en PDF u otros formatos disponibles." The original file only (no conversions).
- S6. (L1) "El propietario solo accede a documentos publicados para él o para su comunidad." / "No puede subir, editar, eliminar ni cambiar la clasificación de documentos generales." / "Importante: utilizar los mismos documentos que gestiona el administrador, pero con permisos de visibilidad. No crear un segundo repositorio documental."
- S7. (L1) "Reutilizar del Administrador: repositorio documental, categorías, buscador, filtros, tabla, visor y descargas." Shared `document-viewer` extracted from the manager's preview dialog and used by both.
- S8. Navigation: the sidebar item opens the new page; the property-detail «Documentos» tab goes away; `?tab=documents`, dashboard «Documentos nuevos» KPI / «Documentos recientes · Ver todos» and document notifications land on the new page.
- S9. Security guarantees (L3: "A nivel de seguridad, visibilidad y permisos revisa que el plan tenga en cuenta el nivel mas alto de garantias en todos los aspectos posibles"):
  - G1 one visibility rule (`documentVisibleWhere` / `RagAuthorizationService`) for list, counts, preview, download and assistant — `/me/documents` reuses it, no parallel rule.
  - G2 restrictive by default; «Interno de la gestora» never reaches owners.
  - G3 only Propietario/Representante with a linked, non-revoked membership; tenants and pending adhesions see no community documents.
  - G4 permission changes apply on the next request (DB, not JWT).
  - G5 not found, other estate, not visible and trashed all answer the same 404.
  - G6 every mutating library route answers 403 to role C (one test per route).
  - G7 downloads audited in data_access_log; G14 preview logged as `view`, download as `download`.
  - G8 no service-worker caching of API responses.
  - G9 abuse tests on `/me/documents` and on direct download by id: neighbour-targeted (PROPERTY), MANAGER, BOARD without a current office term, trashed, other estate, revoked membership, pending membership, tenant, deleted property.
  - G10 filters and category counts computed inside the visible set only.
  - G11 `Cache-Control: private, no-store` on downloads.
  - G12 `Content-Disposition` with RFC 5987 `filename*=UTF-8''…`.
  - G13 preview only for PDF/PNG/JPEG/WebP; authenticated blob, object URL revoked on close, no token in URLs; «Abrir documento» opens that blob in a new tab.
  - G15 minimal response: no `s3Key`, uploader identity, internal folders or other homes' ids.
  - G16 board documents marked «Junta», visible only with a current office term.
  - G17 check PDF preview in a real Chrome behind nginx (CSP `frame-src blob:`) before closing the page (pending from the library plan).
- S10. Out of scope (owner-dashboard S6): global search box and weather widget of the mockup header.
