# Owner issues and requests (role C «Incidencias y solicitudes»)

Objective: a dedicated owner page for issues and requests, reachable from the sidebar, as close as possible to the provided mockup, with issues and tickets unified in one model. Branch `feat/owner-issues` (stacked on `feat/owner-dashboard`). Delivery: ask-on-risk. Runners: `npx ng test` (frontend), `npx jest --testPathPatterns=<pattern>` in `backend/` (integration specs need local Postgres), Playwright `npm run e2e` (demo DB: `E2E_OWNER_EMAIL=propietario@demo.domora.app`, `E2E_OWNER_PASSWORD=Demo2026!`).

## Specs

- S1. Privacy (L1): "Importante: una incidencia privada de una vivienda no debe ser visible para otros propietarios. Las incidencias de zonas comunes podrán mostrarse según los permisos establecidos." Role C only lists, reads, creates, comments and uploads on issues of properties they can access (PropertyAccessService rule); common-area issues of their estates are visible once the scope field exists (S3).
- S2. Unification (L3, L4): "Unifica y simplifica. Los modelos que existan o las rutas que dejen de ser necesarias se podrían llegar a eliminar porque no hay datos reales aún". Tickets are folded into Issue with `category` Incidencia / Solicitud / Consulta / Sugerencia (Documentación and Modificación → Solicitud, Queja → Sugerencia); Ticket, TicketTimelineEntry, the tickets module, `/c/requests`, `/b/requests`, the estate tickets tab and the `ticket` notification category are removed. Adhesion requests stay.
- S3. Model (L1, L2 recommendations): Issue gains `category`, `scope` (private / common area; existing rows → private), `location` (list: "Mi vivienda · <unit>", estate portals and common areas, plus "Otra" free text), `reporterUserId`, status `PendienteInformacion`, `internal` flag on timeline entries, generic attachments (photos and PDF, max 10 MB), "Me afecta también" votes. The current fault type becomes an optional subtype for category Incidencia.
- S4. Indicators (L1): "Indicadores de incidencias abiertas, en curso, resueltas y solicitudes." Resueltas = last 6 months; Solicitudes = non-Incidencia categories not resolved ("En trámite").
- S5. List (L1): "Buscador y botón de filtros avanzados, sin filtros duplicados." / "Listado de incidencias y solicitudes que el propietario tiene permiso para consultar."
- S6. Creation (L1): "Botón «Nueva incidencia o solicitud»." / "Al crear una incidencia o solicitud, el propietario indica asunto, descripción, ubicación y puede adjuntar fotografías o documentos. Si no tiene seleccionada una propiedad el modal deberá proporcionar el listado de las disponibles." Urgency through a guided question instead of a priority selector; duplicate suggestion with "Me afecta también" for common-area issues; draft kept; camera upload on mobile.
- S7. Detail (L1): "Al pulsar una fila de las incidencias, se abre su detalle: descripción, estado, adjuntos y seguimiento cronológico." / "El propietario puede añadir información o responder cuando corresponda." Owner can withdraw while Abierta, reopen within 7 days of resolution, rate the resolution; estimated response time shown; deep link `?issue=`; full-screen detail on mobile.
- S8. Notifications (L1): "Recibe notificaciones cuando cambia el estado o el administrador solicita información." Owner reply to PendienteInformacion returns the issue to its previous status and notifies the manager.
- S9. Limits (L1): "No puede modificar estados internos, asignar proveedores ni gestionar presupuestos." Common-area issues show neither reporter nor attachments to other owners; only the reporter comments.
- S10. Reuse (L1): "Reutilizar del Administrador: formulario de creación, tabla, buscador, filtros, adjuntos, ficha de expediente y seguimiento."
- S11. Navigation (L1): "Vamos a sustituir el menu horizontal de navegación entre menus para el propietario por el sidemenu." The sidebar item opens the new page; the issues tab leaves the property detail; old links (`?tab=issues`, notifications, activity, alerts) redirect.
- S12. Out of scope (owner-dashboard S6): global search box and weather widget of the mockup header.
