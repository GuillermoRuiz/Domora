# Panel de finca (rol B) — rediseño según mockup

Objetivo: reconstruir la ficha de finca `b/estates/:id` con 6 tabs (Resumen, Propiedades, Instalaciones, Proveedores, Contratos, Datos generales) y sus componentes (KPIs, gráficos, listados, avisos).
Rama: feature/finca-dashboard-b-miro. Tests: `npx ng test` (front, Vitest), `npm test` en backend (Jest).

## Specs

- S1: La ficha muestra exactamente 6 tabs: Resumen, Propiedades, Instalaciones, Proveedores, Contratos, Datos generales.
- S2: Las tabs que quedan fuera quedan documentadas para poder recuperarlas fácilmente (ver "Tabs desplazadas").
- S3: Resumen: 5 KPIs, hero, Ingresos vs. Gastos, Distribución de gastos, Próximos hitos, Actividad reciente, Propiedades (últimas 5).
- S4: Se construye módulo a módulo, un commit por unidad, verificado.

## Tabs desplazadas (cómo recuperarlas)

Principio: NO se borra código. `EstateTab` conserva todos los ids y el deep link `?tab=<id>` (estate-detail.component.ts:476-497) sigue funcionando; solo dejan de pintarse en la barra de 6 tabs. Al migrar, el antiguo `ESTATE_NAV_GROUPS` se conserva como `LEGACY_ESTATE_NAV_GROUPS` en `core/estate-navigation.service.ts`; recuperar una tab = añadir su id a la lista visible.

| Id antiguo | Etiqueta | Dónde vive el código | Destino propuesto |
|---|---|---|---|
| properties | Propiedades | inline, estate-detail.component.html:65-145 | tab Propiedades (se mantiene) |
| requests | Solicitudes de adhesión | inline, html:147-186 | oculta; deep link `?tab=requests`; contador en Resumen |
| sepa | Facturación SEPA | inline, html:557-612 | se integra en Datos generales |
| tickets | Solicitudes de vecinos | `<app-tickets-tab>` | oculta; deep link `?tab=tickets` |
| documents | Documentos | `<app-documentos-tab>` | oculta; deep link `?tab=documents` |
| juntas | Juntas | `<app-juntas-tab>` | oculta; KPI "Próxima junta" enlaza a `?tab=juntas` |
| communications | Comunicados | `<app-comunicados-tab>` | oculta; deep link `?tab=communications` |
| issues | Incidencias | inline, html:188-436 | oculta; KPI "Incidencias abiertas" enlaza a `?tab=issues` |
| amenities | Instalaciones | inline, html:438-537 | tab Instalaciones (se mantiene) |
| inspections | Inspecciones | `<app-inspecciones-tab>` | INTEGRADA en Instalaciones (sub-vista por defecto); `?tab=inspections` y los hitos del Resumen siguen valiendo |
| providers | Proveedores y Personal | `<app-proveedores-tab>` / `<app-personal-tab>` | tab Proveedores (Personal como sub-sección) |

Decidido (L3): sin menú "Más". Las tabs ocultas solo son accesibles por deep link y por los enlaces del Resumen (KPIs, hitos, avisos), hasta que llegue la barra lateral global (Incidencias, Juntas, Documentación).
